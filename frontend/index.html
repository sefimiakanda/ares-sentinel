Comprendre les termes affichés

Sol : un jour martien de 24 h 39 min. Le sol 0 est le jour de l’arrivée de Curiosity.

Ls : longitude solaire, indicateur de saison. Indice : comparaison pédagogique avec l’historique Curiosity, pas un seuil NASA.

Anomalie ML : jour statistiquement inhabituel détecté par Isolation Forest ; inhabituel ne signifie pas forcément dangereux.
